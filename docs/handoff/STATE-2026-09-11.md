## 1. What the product is

Needt is a single-user intelligent planner — calendar, tasks, projects,
documents, focus — built from a FluidCalendar fork. One person opens the same
four screens forty times a day, so the interface is an instrument panel, not a
brochure: quiet, dense, monochrome.

The thing no competitor does, and the reason the product exists: **the rail on a
calendar block says whether the scheduler can still move it.** Grey means fixed,
coloured means the scheduler placed it and can place it again.

Multi-user auth and billing exist in the schema; the product experience is
single-user.

```

src/app/api/              route handlers; Next 15 → params is a Promise

src/components/           ai auth boards calendar dnd documents errors focus legal
                          liquid mail moodboards navigation pages projects
                          providers pwa settings setup tasks today ui
src/services/scheduling/  TaskSchedulingService · TimeSlotManager · SlotScorer
                          · CalendarServiceImpl
src/lib/task-sync/        one-way sync from Outlook / Google Tasks, selective fields
src/lib/{google,outlook,caldav}-*.ts, src/lib/token-manager.ts
src/store/                Zustand, one concern per store
src/worker/               BullMQ: provider sync, rescheduling, reminders, nudges
prisma/schema.prisma      2459 lines
```

**Local-first calendar sync.** External calendars are never read live in the UI.
Providers sync into `CalendarFeed` + `CalendarEvent`; the app always reads local
data. Token refresh is central so expired tokens renew transparently.

**Scheduling.** Tasks flagged `isAutoScheduled` receive `scheduledStart/End` and
a `scheduleScore`.

**Task sync field ownership.** External-owned (overwritten each sync): title,
status, due date, recurrence. Local-owned (preserved): start date, duration,
priority, energy level. See `src/lib/task-sync/README.md`.

### Non-negotiable code conventions

- Prisma: import the singleton `prisma` from `@/lib/prisma`. Never
  `new PrismaClient()`. Types from `@prisma/client`.
- Dates: everything through `@/lib/date-utils.ts`, **including `new Date()`**.
  Do not reach for `date-fns` directly.
- Calendar DB access: through `@/lib/calendar-db.ts`.
- Logging: `logger` from `@/lib/logger`, never `console.log`. One `LOG_SOURCE`
  const per file, passed last.
- Admin: `requireAdmin` from `@/lib/auth/api-auth` for routes; `useAdmin` /
  `<AdminOnly>` for UI. Never hand-roll a `getServerSession` role check.
- Notifications: the typed `notify` facade in `src/lib/notifications.ts`. Only
  the facade and the shared Toaster may import Sonner.
- AI companion position math: `src/lib/assistant-position.ts`. Persist
  normalised coordinates; mark fixed controls with `data-assistant-avoid`.
- JSX text: escape as `&apos;` / `&quot;`.
- One unified build. No edition flags, no parallel component variants.
- Update `CHANGELOG.md` under `[unreleased]` for anything user-facing.

### Multi-writer discipline

### The bug that has shipped twice — read this before touching tokens

A CSS custom property whose value contains `var()` is substituted **where it is
declared**, then inherits as a resolved string. Declare a derived token once on
`:root` and the dark theme silently comes out light-grey. Nothing errors.

**Every derived token must be declared in `:root`, `.dark` and `.dim`.**

When verifying, read *computed* styles, not declarations. A frozen token looks
correct in source and wrong on screen.

### Token migration

ordered by real usage counts. Nine names collide across the two systems with
different values: `--background --foreground --border --destructive
--surface-canvas --surface-raised --text-primary --text-secondary --text-muted`.

**Migrate a screen's tokens in one commit, never partially.** A screen is either
fully on the new system or fully on the old one.

`--button-primary-bg` / `--button-primary-fg` (9 call sites) have **no
replacement, by decision** — see rule 4 in `/DESIGN.md`.

## 7. Typography — Exposure, and a live licence risk

The display face is **205TF Exposure**, designed by Federico Parra Barrios,
released 2022, First Prize for Type Design at Le Club des directeurs artistiques
(CDA54) 2023.

Verified from the file's `fvar` table on 2026-09-05:

- one axis, **`EXPO`**, min −100, default 0, max +100
- **the metrics are duplexed** — the word "Needt" measures 319.3px at 112px type
  at all eleven axis positions, 0.0% deviation. Nothing in a layout can move when
  the axis animates, so **no width-lock machinery is needed anywhere**
- 119 glyphs: A–Z, a–z, 0–9, punctuation. **No Cyrillic.**

What the axis does: at 0 the face is a crisp Didone. Going negative it
underexposes — strokes swell, counters fill, at −100 the letters nearly fuse into
a black mass. Going positive it overexposes — strokes burn away, at +100 the
letterforms fragment.

Files in `design-refs/fonts/` (45 files): `ExposureTrialVAR.ttf` (440 KB),
`ExposureTrialVAR-Italic.ttf`, `ExposureTrialVAR.woff2` (217 KB, converted
2026-09-05), plus 42 static cuts at 10-point intervals.

⚠️ **These are TRIAL files: testing only, no commercial use, no redistribution.**
`design-refs/fonts/` was added to `.gitignore` on 2026-09-06. **A web licence
must be bought from 205TF before the wordmark ships.** Price is behind their JS
configurator and was never retrieved — do not guess it.

**Live violation to fix:** the Today → Canvas header sets "1 September · Tuesday
· week 36" in the display serif. Month and weekday names are translatable, the
account menu already offers a Language item, and Exposure has no Cyrillic. Either
those strings move to sans, or the header renders the numeral in serif and the
words in sans.

Body sans: Inter first, falling through to `system-ui`. Apple's licence forbids
shipping SF as a webfont; `system-ui` resolves to real SF on macOS at zero bytes.

## 8. `ExposureWordmark` — built, lives only in Claude Design

Five modes on one component. This is the **only** licensed exception to the
"motion must be caused" rule.

| Mode | Behaviour |
|---|---|
| **develop-in** | `EXPO` −100 → 0, 620ms, `cubic-bezier(0.215,0.61,0.355,1)` (easeOutCubic), stagger 85ms per letter. Fires once on mount. Reads as a print coming up in the tray. |
| **breathe** | 0 → −30 → 0, 5200ms cycle, easeInOut, infinite, phase offset 260ms per letter. The 20% phase spread is what makes it a travelling wave rather than a synchronised throb. |
| **pulse** | current → +70 → back onto the breathe curve. 1300ms, times `[0,.35,1]`, easeOutExpo, stagger 80ms, every 6000ms. **Opposite direction to breathe** — breathe inks, pulse burns. That contrast is the idea; Dia runs both in one direction. |
| **torch** | Pointer-driven. Per letter: `d = |cursorX − letterCenterX| / 180`, `t = 1 − smoothstep(0,1,clamp(d,0,1))`, `target = lerp(0, 55, t)`. Each letter driven by a **spring** — stiffness 220, damping 26, mass 1 — never direct assignment. The ~80ms lag is the whole effect. |
| **busy** | Bound to the scheduler writing. → `EXPO` 55 over 300ms easeOut, hold; → 0 over 400ms. Capped at 55; past ~60 strokes fragment and it reads broken, not lit. |

Composition, one resolved value per letter per frame:

```
base  = breathe(t) + pulse(t)
torch = lerp(0, 55, tCursor)              // spring 220/26/1
value = clamp(base + torch, -100, 100)
if (busy)       value = 55                // overrides
if (developing) value = developIn(t)      // overrides, hands over on completion
```

On `pointerenter` the breathe amplitude scales to 0 over 250ms so the torch reads
clean; back to 1 over 400ms on leave.

Sizes: 112px hero, 64px sign-in, 28px sidebar. **At 28px the axis is clamped to
−40…0** — positive values thin the strokes until they vanish on the light theme,
so pulse is disabled there. Below 28px: static.

Reduced motion, offscreen, or hidden tab: all five off, static at `EXPO` 0. The
rAF loop pauses and resumes at its stored phase, not from zero.

### Two traps found while building this

- **CSS `animation-delay` without `animation-fill-mode: both`** leaves a letter
  at its resting value during its delay, then snaps. Use `both`.
- **CSS animations outrank inline styles in the cascade.** A finished
  `forwards`-filled animation silently swallows every `el.style.fontVariationSettings`
  write, so the JS-driven torch does nothing. On `animationend`, remove the
  animation class and write the current value inline before handing over.

## 9. Decisions taken 2026-09-05 / 06, all recorded in `/DESIGN.md`

**The two-transition motion limit is lifted.** The old rule said "two transitions
and no more — theme crossfade and hover" and "no entrance animations". Both
reversed. Motion is now judged per surface, not by a count, under one test:
**motion must be caused.** It reports a real event — a mount, a state change, the
pointer, the scheduler. Motion on a timer with no cause stays banned everywhere
except the wordmark.

**The schedule re-flow no longer holds the animation budget.** There is no single
budget. `design-refs/wow-animations-brief.md:16` still claims otherwise — that
line is dead; its libraries, springs and timings stand.

**The sale flame is cancelled.** `docs/plans/11-task-model.md` §3 permitted one
transient flame on a real sale and explicitly banned ambient flame at rest. The
built app had ambient flame on **overdue tasks** — the opposite. Flame is now
removed from the product entirely. That section is marked CANCELLED and kept as
the record of why the exception was drawn narrowly.

**Overdue reads as exposure, not ornament.** Red rail, plus the title at
`EXPO −40` easing to 0 over 400ms easeOut when the task is opened, rescheduled
or completed. No fill change, no border, no flame, no red on the time or title.

**Serif is allowed at display sizes, 28px and up**, reversing §3 of 2026-08-23.
Never on a translatable string. Face changed from Instrument Serif to Exposure.

**The rail meaning became a user setting.** Settings → Appearance now ships
**Rail language: Movability | Urgency**, built without being recorded. The
2026-08-23 reasoning still holds and is what makes it safe — only one meaning is
ever live. Two consequences: the legend line under the canvas must change with
the setting, and **no document may state "grey is fixed" as a fact**, because it
is false for anyone on Urgency. Movability stays the default.

**Money is not the spine of the product.** Owner, 2026-09-06: "не все же
ресейлом занимаются". The VALUE column stays but **hides when no task in the
whole group carries an amount**. T-4 value-bearing groups remain a real feature,
not a default frame.

**Backdrop blur: `/DESIGN.md` rule 6 is the only authority.** Blur appears
exactly once, on the floating action. Four files disagreed —
`ui-conventions.md:45` and `docs/plans/09-launch.md:403` said the ban is retired,
`wow-animations-brief.md:28` and `docs/plans/03-motion-ui.md:14` said blur is
forbidden. All four are superseded on this point. The ban being lifted was about
*permission*; the rule is about *consistency*.

### Still contradictory, not yet resolved

- **`DESIGN.md` rule 4** — "the accent is never a solid fill on a button, solid
  accent is permitted only on marks." The Chat panel's send button is a solid
  blue circle. Either the rule changes or the button does.
- **`DESIGN.md` rule 3** — "no 14px in the chrome; the interface runs at 13 and
  12." `design-refs/board-tokens.md` is superseded but kept "for its
  measurements", and it is full of 14px paddings, radii and icon sizes. An agent
  fetching a measurement from it imports the 14.

## 11. Calendar — rebuilt 2026-09-06, five defects open

Geometry was extracted into `CalendarGrid.jsx` (in Claude Design only).

**Landed and verified from the screenshot:** 56px/hour standard, 44px compact,
07:00–22:00 visible (840 / 660px); 48px gutter, 11px right-aligned labels on the
hour line; all-day is one row with a `+2` chip and a popover; content-by-height
ladder (<22px title only / 22–40 title + right-aligned time / 40–70 two lines /
>70 plus a meta line with project dot and part counter), nothing wraps; **event =
tinted fill, no border; task = surface card + hairline + 3px rail + checkbox**;
colour carried by the rail only, project identity a 6px dot above 40px; splitting
now happens only on genuine overlap; empty columns keep full height; now-line
present on Week; Month built as 6×7 with "+N more" and an accent ring on today.

### Open defects — the fix prompt was written, the result never came back

1. **Cascade never fires.** Wed: `Factory call 13:00–14:00` and `Pri… 13:30–15:00`
   overlap 30 min — 50% of the first and 33% of the second, so both are under
   half and the pair must cascade. It split, and a 90px block showed three
   letters. The condition is being tested against one duration, not both.
   Required: `if (overlap < 0.5*durA) AND (overlap < 0.5*durB)` → cascade, later
   block indents 12px, takes remaining full width, draws above, carries the
   hairline ring.
2. **Width ladder missing.** `<120px` drop the project dot; `<90px` take the
   checkbox out of flow (rail thickens 3px → 5px, checkbox on hover overlaid);
   `<64px` the cluster does not split at all — it becomes one chip ("3 events")
   spanning the column, click opens a popover in place reusing the `+2` component.
3. **Short events render as dividers.** `Stand-up`, `Book the dentist` are a
   rail + title + bottom hairline on transparent ground. Minimum block height
   18px, and an event **always** carries its tinted fill at every height.
4. **Overdue time outshouts the title.** Time is red and larger than 11px, so a
   full-width block truncates its title. Time stays 11px muted like everywhere
   else; red appears on the rail and nowhere else.
5. **Now-line dot** sits on the column boundary and reads as the previous day.
   Inset it 4px into today's column.

Settled rules for the algorithm: **cascade only for pairs**; three or more always
split n ways with a 4px gutter, ordered by start then duration descending; the
`<64px` chip opens a popover in place.

**Colour count is at its ceiling.** Four hues on screen — blue, amber, green,
red. A fifth project breaks it. Cap the project palette at six hues with at most
four live on one screen; the rest take a neutral dot.

## 14. Accepted design concepts not yet built — D7

Each built on a mechanism from outside product design. Recorded in
`docs/plans/10-design.md`.

- **Margin marks after a reschedule.** From letterpress proof correction: the
  change is a persistent mark in the margin, not a re-animated block, so the day
  is readable by scanning rather than re-reading. *This is the receipt half of
  the agent cursor.*
- **Three states of slack, with "you will make it" drawn.** From hydrographic
  charts, which give safe water its own symbol and encode steepness through
  contour spacing. The one that changes a decision the user makes today.
- **A Marey chart for the day.** From the 1878 graphical train schedule, where
  slope is speed: falling behind reads as an angle, not a number.
- **A calendar mode without a clock axis.** From heijunka production levelling.
  Ships as a switchable second mode with the sidebar changing with it — which is
  what makes it testable.
- **Workspace staves** — each workspace holds a fixed vertical position and stays
  visible when empty, like a silent instrument in a score. *Considered, no
  verdict.*

Task model, `docs/plans/11-task-model.md`: **T-1** progress counter and part-cut
(accepted into backlog — `targetCount`, `completedCount`, named parts reusing the
existing subtask relation, no `taskType` enum, no picker at creation). **T-2**
mini-entry, gated on T-1 plus a prompt-quality check: export twenty tasks
rescheduled 2+ times, run the prompt by hand, and if fewer than twelve produce a
first action you would actually perform, it does not ship. **T-3** streaks,
parked: in a planner the user authors the tasks, so one trivial task closes the
day — no streak until there is a definition of a closed day that cannot be farmed.

**Not authorised, unchanged:** a new AI scheduler, seat billing, cross-workspace
views, third-party document storage, physical deletion of user content, read
receipts, team snippets, Notion-style automation, portfolio management, audio
transcription, new integrations.

## 15. Verification habits that caught real errors this cycle

- **Measure, don't eyeball.** "It's a solid fill" was wrong —
  `rgba(46,109,233,0.12)`. "Text is clipped" was wrong — zero nodes had
  `scrollWidth > clientWidth`.
- **Read computed styles, not declarations**, when checking tokens. A frozen
  derived token looks right in source.
- **A failing MCP connector says nothing about the underlying operation.** A
  broken GitHub connector was reported as "push is blocked"; `git push --dry-run`
  returned exit 0. Different credentials. Test the actual operation.
- **Render motion as a frame strip.** A grid of resting states cannot be judged.
  Six stills across the animation, each labelled with its values, makes it
  reviewable from a screenshot.
- **Each `bash` call is a separate process.** Start a server and use it in the
  same call or it is gone.
