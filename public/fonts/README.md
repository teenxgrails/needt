# Exposure

`ExposureVAR.woff2` — 205TF Exposure, one axis `EXPO` from −100 to +100, 203
glyphs, no Cyrillic. The display face, and the wordmark's own.

**Its internal name records say "Trial".** Family reads `Exposure Trial VAR` and
the version string carries `288130-trial-…`. That is not an oversight and not the
wrong file: the owner holds a web licence in their 205TF account, and 205TF
support confirmed on 2026-09-12 that this is the file to use. The binary the
foundry serves is the same one; the licence is the grant, not a different file.

Recorded here because the next person to open it will otherwise read "Trial" and
assume a mistake.

**The rule that still holds**: no Cyrillic in the face, so the display serif never
carries a translatable string. Month and weekday names stay in the sans.
