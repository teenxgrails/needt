# Attic

Nothing here is loaded by the site. It is kept because it works and may be
wanted again, not because it is in use.

- **archive-film-block.html** — three lifted pieces of the landing, each whole
  and each with a note saying what it needs from a host page: the looping film
  of the product placing a day, the integrations belt, and the pinned scenes
  "the day assembles" and "what the rail means". Paths inside are already
  rewritten for this folder's depth.
- **archive-facts-band.html** — the three-card band that sat between the steps
  deck and "the rest of the week" (stop replanning · one button · nothing gets
  lost). Retired 15 September 2026. Its header note says which CSS and which
  block of `land.js` it needs, and records that its three figures — 5h, 1, 0 —
  were cut earlier for having no source.
- **archive-price-block.html** — the landing's price section: three plan cards
  (demo / Pro $7 / Life $149 for the first 300) and the twelve-row plan table.
  Retired 16 September 2026. The prices themselves are unchanged and still live
  on `pricing.html`, which the nav still links — this retired the section, not
  the price. Its header note lists the CSS and the `.l-rise` observer it needs. The file also
  holds the one-line **price plate** that briefly stood in for the section in the
  footer the same day, with its own `.l-plate` CSS lifted out of
  `land-life.css` — nothing on the site uses those classes now.
- **needt-app-App.stale.jsx** / **needt-app-Habits.stale.jsx** — older copies of
  two app files that were written to the project root by a bad path. The live
  versions are in `needt-app/`.
